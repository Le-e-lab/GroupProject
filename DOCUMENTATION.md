# UPath – Technical Documentation

## 1. System Architecture

### Backend (Node.js + Express + Sequelize)
- **Runtime**: Node.js with Express.js framework
- **Database**: SQLite (`timetable.sqlite` in project root) via Sequelize ORM
- **Authentication**: bcrypt password hashing + session-based auth via `sessionStorage`
- **API Base**: All routes served under `/api/`

### Frontend (HTML5 + Vanilla JS)
- **Styling**: CSS custom properties in `css/theme.css` for a consistent design system
- **Logic**: `public/js/api.js` — centralised API wrapper for all server calls
- **Libraries**: `html5-qrcode` (QR scanning), `Chart.js` (analytics charts)

## 3. Key Workflows

### A. Lecturer — Generating an Attendance Code
1. Lecturer logs in and goes to **QR Code** page
2. Selects their active class from the dropdown
3. Clicks **"Generate Code"** → `POST /api/attendance/generate-code`
4. Server creates a TOTP session with a 2-hour expiry and returns a 6-digit code
5. Code refreshes automatically every 30 seconds

### B. Student — Marking Attendance
- **Via 6-digit code** (`enter_code.html`): Student types the code shown by lecturer → `POST /api/attendance/validate-code`
- **Via QR scan** (`scan_qr.html`): Uses rear camera to scan the QR code (requires HTTPS/Ngrok on mobile)
- Both methods record a row in `Attendances` with `classId`, `userId`, `date`, and `method`

### C. Analytics
- Lecturers see per-class attendance stats via `GET /api/attendance/stats/course/:courseId`
- Dashboard auto-detects current class based on day/time from the timetable

## 5. Setup & Running

### Local Development
```bash
npm install
npm start
# Visit http://localhost:3000
```

### Mobile Testing (via Ngrok)
```bash
ngrok http 3000
# Copy the https://....ngrok-free.app URL to test on mobile devices
```

### Re-seeding the Database
```bash
node server/scripts/seed_all.js       # Wipes and re-seeds all users & classes
node server/scripts/seed_attendance.js # Adds realistic attendance history
```

## 6. Troubleshooting

| Problem | Solution |
|---------|----------|
| Camera not working | You must use the **HTTPS** Ngrok URL on mobile (not http) |
| Network error on login | Server must be running (`npm start`) on port 3000 |
| Invalid credentials (lecturer) | Use Staff ID `210153` and password `staff123` |
| Invalid credentials (student) | Use ID `240101` and password `password123` |
| No classes on dashboard | Student's `program` field must match `Program` column in timetable |
